# Aside Block

Two-column layout with configurable split. Image can be left or right.

## Authoring

| Column 1 | Column 2 |
|----------|----------|
| Image (picture only) | Content (heading, text, etc.) |

Or swap columns for image on the right:

| Column 1 | Column 2 |
|----------|----------|
| Content | Image (picture only) |

## Column Split

Add class `split-X-Y` where X + Y = 100. First column gets X%, second gets Y%.

- `split-60-40` – 60% / 40%
- `split-30-70` – 30% / 70%
- Default: 50% / 50%

Example: `aside split-60-40`
